# 手搭 Qwen-Image 2512（不 Unpack、不用一体化子图）

你要的流程：**空白画布 → 自己加节点 → 在节点上下拉选模型**。  
不要打开 Templates 子图，不要 Unpack。

---

## 0. 开始前

1. 新建空白工作流（Clear / 新建）  
2. 确认文件已在：

```text
models/diffusion_models/   ← 官方 qwen_image_2512_fp8… 或能用的国漫
models/text_encoders/      ← qwen_2.5_vl_7b_fp8_scaled.safetensors
models/vae/                ← qwen_image_vae.safetensors
models/loras/              ← 美术电影 LoRA
```

3. 加节点时：**双击画布搜索英文名**，添加后 **只左键点下拉选文件**，不要从下拉往外拖线。

---

## 1. 要加的节点清单（按顺序搜）

| # | 搜索名 | 作用 |
|---|--------|------|
| 1 | `Load Diffusion Model` | 选底模（unet） |
| 2 | `Load LoRA` | 选美术电影（只要改 MODEL 时可用 Model Only 版） |
| 3 | `ModelSamplingAuraFlow` | Qwen 采样补丁，`shift` = **3.1** |
| 4 | `Load CLIP` | 选文本编码器 |
| 5 | `Load VAE` | 选 VAE |
| 6 | `CLIP Text Encode` | 正面提示词 |
| 7 | `ConditioningZeroOut` | 做空负面（接正面 conditioning） |
| 8 | `EmptySD3LatentImage` | 画布尺寸（不要用普通 Empty Latent Image） |
| 9 | `KSampler` | 采样 |
| 10 | `VAE Decode` | 解码 |
| 11 | `Save Image` | 保存 |

---

## 2. 每个节点选什么模型 / 参数

### Load Diffusion Model
- 下拉选：`qwen_image_2512_fp8_e4m3fn.safetensors`（先用官方跑通）  
- 国漫若也在 `diffusion_models` 且能选到，再换成国漫  
- `weight_dtype`：`default`

### Load CLIP
- 下拉选：`qwen_2.5_vl_7b_fp8_scaled.safetensors`  
- `type`：选 **`qwen_2.5_vl`**（有的版本写作 `qwen_image`，与模板一致即可）

### Load VAE
- 下拉选：`qwen_image_vae.safetensors`

### Load LoRA
- 下拉选：**美术电影**  
- `strength_model`：**0.8**（先求稳可先 0）  
- 若节点有 CLIP 强度且你只用 Model 路，CLIP 强度可 0 或改用 `Load LoRA` 的 Model Only

### ModelSamplingAuraFlow
- `shift`：**3.1**（非 Lightning 加速时）

### EmptySD3LatentImage
- 先 **1328 × 1328**，batch 1  
- 再改 16:9：**1664 × 928**

### KSampler（无 Lightning 时）
- steps：**30–50**  
- cfg：**3.5–5**（可先 4）  
- sampler：`euler`  
- scheduler：`simple`  
- denoise：`1`

### 提示词（CLIP Text Encode）
```text
中国上影美影动画风格，天书奇谈气质，工笔勾线，平涂着色，
聊斋狐女，冷青夜色，烛火，水墨远山，电影静帧
```

---

## 3. 连线（照这个接）

```text
Load Diffusion Model ──MODEL──► Load LoRA ──MODEL──► ModelSamplingAuraFlow ──MODEL──► KSampler.model

Load CLIP ──CLIP──► CLIP Text Encode ──CONDITIONING──► KSampler.positive
                         │
                         └──► ConditioningZeroOut ──CONDITIONING──► KSampler.negative

EmptySD3LatentImage ──LATENT──► KSampler.latent_image

KSampler ──LATENT──► VAE Decode ──IMAGE──► Save Image
Load VAE ──VAE─────► VAE Decode
```

---

## 4. 若「还是只能接线、点不开下拉」

那是单个节点控件也被转成输入了。手搭时：

1. **删掉该节点，重新双击添加一个全新的**  
2. 添加后立刻 **左键点文件名下拉**，不要拖线  
3. 仍不行：选中节点 → 右侧 **Properties Panel** 里填完整文件名  

不要再用 Templates 一体化子图。

---
