1. 下载 Windows builds
2. 解压到如 `C:\ffmpeg`
3. 将 `C:\ffmpeg\bin` 加入系统 PATH
4. 终端执行 `ffmpeg -version` 验证

## 8. 本仓库冒烟测试命令（可选）

装好 FFmpeg 后，可用下面命令检查环境（在工程根目录）：

```bash
ffmpeg -version
mkdir -p 08-export/_smoke
# 生成 3 秒黑场测试片（验证 ffmpeg 可用）
ffmpeg -f lavfi -i color=c=black:s=1920x1080:d=3 -c:v libx264 -pix_fmt yuv420p 08-export/_smoke/black_3s.mp4
```

成功生成 `08-export/_smoke/black_3s.mp4` 即表示本机转码链路正常。
