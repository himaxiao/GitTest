# RTX 4080 Super 本机环境手册（你的配置）

显卡：**RTX 4080 SUPER · 16GB VRAM**  
推荐路线：**本机 ComfyUI 出图/精修为主 + 可灵等云端图生视频 + 本机剪辑**

16GB 显存足够舒适跑：

- SDXL 1024–1536（批量、ControlNet、IP-Adapter 同开）
- Flux.1 Dev（fp8 / 量化权重更稳）
- 部分轻量本机图生视频（AnimateDiff / 小模型试玩）
- 不建议把「成片级长镜头视频」全压在本机——可灵等云端质量与稳定性仍更好

## 1. 你的标准工具栈（按顺序装）

| 顺序 | 软件 | 作用 | 验收 |
|------|------|------|------|
| 1 | 最新 **Game Ready / Studio** NVIDIA 驱动 | CUDA 推理 | `nvidia-smi` 能看到 4080S、驱动版本 |
| 2 | **Git** | 拉 ComfyUI | `git --version` |

> Windows 上若已装多个 Python，务必确认终端里的 `python` 是 3.11，避免 3.12 插件兼容坑。

### Day 1：ComfyUI 本体

**方式 A（推荐新手）：便携包**

1. 打开 ComfyUI 官方 Releases / 社区 Windows portable 包（含嵌入式 Python）
2. 解压到非中文、非空格路径，例如：`D:\AI\ComfyUI`
3. 双击 `run_nvidia_gpu.bat`
4. 浏览器打开 `http://127.0.0.1:8188`

**方式 B：Git 源码（方便更新）**

在 `D:\AI\` 下：

```bat
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python -m venv venv
venv\Scripts\activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
python main.py
```

> CUDA 轮子版本随时间会变；以 PyTorch 官网当前 `cu12x` 指令为准。4080S 选 **CUDA 12.x + 较新驱动** 即可。

装好后立刻装 **ComfyUI-Manager**（方便点选插件）：

```bat
cd ComfyUI\custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
```

重启 ComfyUI，右上角应出现 Manager。

**验收：**

- [ ] 页面能开
- [ ] Queue 能跑通默认工作流（哪怕先用小图）
- [ ] Task Manager / `nvidia-smi` 出图时 GPU 利用率上升

## 2. 4080S 模型清单（先下这些，别一次下光硬盘）

磁盘建议单独盘：`D:\AI\ComfyUI\models\...`，预留 **150–250GB**。

### 2.1 底模（Checkpoints）— 先 2 个

| 优先级 | 类型 | 用途 | 放置 |
|--------|------|------|------|
| ★★★ | **SDXL** 通用/插画底模 | 分镜、角色、批量稳定 | `models/checkpoints/` |
| ★★★ | **Flux.1 Dev**（fp8 或官方 + 量化） | 高质量定妆、海报级静帧 | `checkpoints/` 或 Flux 工作流指定目录 |
| ★★（可选） | 国风专用 SDXL merge | 更贴近水墨/工笔 | `checkpoints/` |

在 Liblib / Civitai 搜索关键词：`SDXL` `anime illustration` `国风` `水墨` `工笔`。

### 2.2 国风 LoRA — 先 3 个以内

| 关键词 | 用途 |
|--------|------|
| 水墨 / ink wash | 山雾、远景、氛围 |
| 工笔 / gongbi | 人物勾线 |
| 古风人物 / 神怪 | 聊斋角色 |

放置：`models/loras/`  
权重习惯：先 **0.6–0.85**，避免脸崩或风格过曝。

### 2.3 控制与一致性（短片必备）

| 组件 | 用途 | 4080S 建议 |
|------|------|------------|
| **ControlNet SDXL** lineart / softedge / depth | 锁构图、锁线稿 | 可同时开 1–2 个 |
| **IP-Adapter**（Plus Face / 普通） | 锁角色长相 | 与 SDXL 搭配优先 |
| **InstantID** 或 FaceID（可选） | 更强锁脸 | 显存够，可后装 |

通过 ComfyUI-Manager 安装对应节点，再按插件说明下载模型文件到指定目录。

### 2.4 VAE / 文本编码器

- SDXL：多数 checkpoint 已内嵌；缺了再下官方 SDXL VAE
- Flux：按你使用的 Flux 工作流包说明，补齐 `clip` / `vae` / `unet` 分件

## 3. 4080S 出图参数甜点区

### SDXL（日常分镜 / 批量）

| 项 | 建议 |
|----|------|
| 分辨率 | 1024×1024 定妆；分镜用 1344×768 或 1216×832（16:9） |
| Steps | 25–35 |
| CFG | 5–7（LoRA 多时略降） |
| Batch | 2–4 张很轻松 |
| 精度 | fp16 默认即可 |

### Flux（精品定妆 / 关键场景）

| 项 | 建议 |
|----|------|
| 分辨率 | 1024–1280 边长 |
| 量化 | fp8 / Q5–Q8 更省显存更稳 |
| 用途 | 少而精，不要每镜都用 Flux 硬刷 |

### 显存不够时的急救（一般 4080S 很少碰到）

- 关预览高清、降 batch
- ControlNet 只留 1 条
- Flux 改用更强量化
- 启动加：`--lowvram` 仅作急救，4080S 正常不需要

常用启动（源码版可改 bat）：

```bat
python main.py --preview-method auto
```

## 4. 本机负责什么 / 云端负责什么

| 环节 | 4080S 本机 | 云端 |
|------|------------|------|
| 风格探索、角色定妆 | ✅ ComfyUI | 可辅助对比 Midjourney/即梦 |
| 分镜关键帧批量 | ✅ 主力 | — |
| 修脸、统一色调、线稿重绘 | ✅ + Krita | — |
| 图生视频 4–5s 镜头 | 可试 AnimateDiff，**成片建议可灵** | ✅ **可灵主力** |
| 配乐配音 | — | Suno + TTS |
| 剪辑成片 | ✅ 剪映/Resolve | — |

一句话：**静帧尽量本机控死风格；动起来交给可灵。**
