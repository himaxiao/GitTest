# 试片脚本：《青凤》夜遇（节选）

## 出处与取舍

- 原典：蒲松龄《聊斋志异·青凤》
- 本片只取开篇气韵：**荒园夜色，书生窥见狐女烛下仪态**（不讲完爱情与叔父线）
- 视觉锚点：你现有的**狐女定妆**（青袍、花钿、烛火、冷青远山）
- 制作约束：本地 Qwen 静帧 + Wan2.2-5B 短段 I2V；运动以 A 级为主（烛火/微动）

## 一句话

荒园夜里，书生听见笑声，推开柴扉，只见狐女立于烛火之侧——对视一眼，风动烛摇。

## 分镜表

### S01 · 荒园夜门（8s）

| 项 | 内容 |
|----|------|
| 景别 | 全景 / 大远景偏全 |
| 首帧任务 | Qwen 出「冷青夜色、荒园柴扉、远山」静帧（可无人物或极小剪影） |
| 画面 | 夜色压园，柴门半掩，远山如墨 |
| 允许运动 | 仅雾气/树影极微动；或几乎静帧 + 缓慢推近 |
| 禁止 | 人物走路、剧烈摇镜 |
| 旁白 | 「耿生夜过荒园，闻笑语切切。」 |
| 声音 | 夜风、远处极轻笑声（后期加） |

### S02 · 门隙烛光（8s）

| 项 | 内容 |
|----|------|
| 景别 | 中景偏近（门缝/门内一角） |
| 首帧任务 | 门内烛火，暖点破冷青；不见脸或只露衣角 |
| 画面 | 门缝里一点烛火，青袖一角 |
| 允许运动 | **仅烛火摇曳** |
| 禁止 | 运镜乱抖、人物转头 |
| 旁白 | 「扉启处，烛影摇青。」 |
| 声音 | 烛火噼啪极轻 |

### S03 · 狐女定妆（14s）★ 主镜头

| 项 | 内容 |
|----|------|
| 景别 | 中景 / 三分之四侧面半身 |
| 首帧任务 | **直接使用你的主定妆图**（3/4 侧看烛） |
| 画面 | 狐女立于烛侧，花钿桃腮，青袍红绦，神情安静 |
| 允许运动 | 烛火摇曳 + 衣袖或发丝**极轻**微动（二选一，先只烛火更稳） |
| 禁止 | 眨眼、张嘴、转头、走路、推镜猛抖 |
| 旁白 | 「有女在侧，绰约若仙，而不类人间温软。」 |
| 声音 | 烛火；旁白结束处笑声戛然而止 |

### S04 · 对视将散（10s）

| 项 | 内容 |
|----|------|
| 景别 | 中近景（可略偏正面的脸部锚点图作首帧） |
| 首帧任务 | 用脸部锚点定妆，或定妆微改「目光望向画外」静帧 |
| 画面 | 她似有所觉，目光轻轻掠过门外——未及言语 |
| 允许运动 | 烛火；目光可保持静，靠剪辑暗示「察觉」 |
| 禁止 | 明显转头、表情狰狞变化 |
| 旁白 | 「四目相对。风一夕，烛穗斜。」 |
| 声音 | 夜风起；淡出 |

**总时长：** 8+8+14+10 ≈ **40s**
