# 半身定妆 → 图生图出全身（操作单）

> 核心：**半身 → 带 Mask 只重绘下方（或 PS/即梦扩图）。**  
> 纯色留白 + 整图低 denoise = 下半截色块（已踩坑，停用）。

---

## 零、先记住

```text
错误：半身 → 纯色加高 → 整图 denoise0.5 → 色块 ❌
错误：半身 → 整图 denoise 想「长出腿」❌
正确：半身 → ImagePadForOutpaint + Mask → denoise1 只画下方 ✅
正确：半身 → PS/即梦选中下方生成式填充 ✅
```

你这张狐女半身：**上半身已合格，不要重抽脸。**

---

## 路线 A（最快）：Photoshop / 即梦扩图

适合立刻出结果，不必改 Comfy 节点。

### Photoshop（有生成式填充）

1. 打开半身竖图  
2. **图像 → 画布大小**  
   - 宽度：**不变**  
   - 高度：改为约 **1.6～1.8 倍**（例如原高 1664 → 新高约 **2800～3000**）  
   - 锚点点选 **上方中间**（人留在顶部，空白全在脚底）  
3. 用矩形选区选中 **下方空白**（可略吃进袍摆 20～40px，方便衔接）  
4. **生成式填充**，提示词：

```text
同一青绿长袍下摆与裙褶自然延伸，白袜或绣鞋，站立地面，冷青远山背景向下延续，工笔平涂天书奇谈风格，完整双脚可见，不要新的人脸，不要改变上半身
```

5. 多抽几次选衔接自然的；导出 `CHAR_青凤_全身_竖_v01.png`

### 即梦

上传半身图 → 用 **扩图 / 智能扩图**，方向勾选 **向下**，比例变高，提示词同上。

---

## 路线 B：ComfyUI **带遮罩扩图**（整图低 denoise 会出「色块」）

> 失败现象：上半身还在，下半截是纯色块。  
> 原因：整图 `denoise 0.45~0.65` 会把大面积纯色留白当成「要保留的背景」。  
> **必须用 Mask，只重绘下方。**

### B1. 用原半身图（不要用纯色留白 PNG 整图重绘）

`Load Image` 选 **未加高的半身定妆**（928×1664 那张人像）。

### B2. 节点（按这个搜、这样接）

| 节点 | 设置 |
|------|------|
| `Load Image` | 半身定妆 |
| `ImagePadForOutpaint`（或 `Pad Image for Outpaint`） | left=0, right=0, top=0, **bottom=1200~1400**，feathering=**40~80** |
| `VAE Encode` | 接 Pad 后的 IMAGE |
| `SetLatentNoiseMask` | samples←VAE Encode；mask←Pad 的 MASK |
| `KSampler` | latent←SetLatentNoiseMask；**denoise=1.0**（只影响蒙版区） |
| LoRA | 0.5~0.7 |

连线：

```text
Load Image ──IMAGE──► ImagePadForOutpaint ──IMAGE──► VAE Encode ──LATENT──► SetLatentNoiseMask ──LATENT──► KSampler
                              │                                              ▲
                              └────MASK──────────────────────────────────────┘
Load VAE ──VAE──► VAE Encode
         └──────► VAE Decode

Load Diffusion → LoRA → AuraFlow → KSampler.model
CLIP Text Encode → KSampler.positive
ConditioningZeroOut → KSampler.negative
KSampler → VAE Decode → Save Image
```

**不要再接** `EmptySD3LatentImage`。  
**不要**对「纯色留白大图」做无 Mask 的整图 img2img。

### B3. 提示词（只描述要补的下半）

```text
延续青绿长袍下摆与裙褶，站立双脚与绣鞋完整可见，冷青远山背景向下延伸，工笔平涂天书奇谈风格，full body lower half, feet visible, seamless continuation
```

### B4. 若找不到 ImagePadForOutpaint

立刻改走 **路线 A（PS / 即梦）**，不要继续空调 denoise。

| 现象 | 处理 |
|------|------|
| 仍是色块 | 确认 Mask 已接入 SetLatentNoiseMask；denoise=1 |
| 脸被改了 | feathering 加大；或 Mask 不要吃到胸口以上 |
| 无 SetLatentNoiseMask | 换路线 A |

---

## 路线 C：整图低 denoise（已验证易出色块 · 停用）

对纯色留白图做 denoise&lt;1 的整图重绘 → **容易下半截色块**。本项目不再推荐。
