# 半身定妆 → 图生图出全身（操作单）

> 核心：**先加高画布，再图生图。**  
> 原图画幅不变直接 img2img = 仍然半身，只是换脸换褶。

---

## 零、先记住

```text
错误：半身图 → 图生图(denoise) → 还想「长出腿」❌
正确：半身图 → 下方留白加高 → 图生图/扩图 → 腿画进空白里 ✅
```

你这张狐女半身：**上半身已合格，不要重抽脸。**

---

## 路线 A（最快）：Photoshop / 即梦扩图

适合立刻出结果，不必改 Comfy 节点。

### Photoshop（有生成式填充）

1. 打开半身竖图  
2. **图像 → 画布大小**  
   - 宽度：**不变**  
   - 高度：改为约 **1.6～1.8 倍**（例如原高 1664 → 新高约 **2800～3000**）  
   - 锚点点选 **上方中间**（人留在顶部，空白全在脚底）  
3. 用矩形选区选中 **下方空白**（可略吃进袍摆 20～40px，方便衔接）  
4. **生成式填充**，提示词：

```text
同一青绿长袍下摆与裙褶自然延伸，白袜或绣鞋，站立地面，冷青远山背景向下延续，工笔平涂天书奇谈风格，完整双脚可见，不要新的人脸，不要改变上半身
```

5. 多抽几次选衔接自然的；导出 `CHAR_青凤_全身_竖_v01.png`

### 即梦

上传半身图 → 用 **扩图 / 智能扩图**，方向勾选 **向下**，比例变高，提示词同上。

## 路线 B：ComfyUI 图生图（Qwen 手搭改造）

在你现有文生图工作流上改，不新建复杂系统。

### B1. 先做「加高留白图」（必做）

任选一种：

**方法 1 · 画板软件**  
画布加高、人置顶、下方纯色接近背景蓝，导出 PNG。  
建议尺寸例：宽与原图相同，高 = 原高 × 1.7（再取 16 的倍数更稳）。

**方法 2 · Comfy 节点**（有就用）  
搜并试：`ImagePadForOutpaint` / `Pad Image for Outpaint` / `Image Pad`  
- left/right/top = **0**  
- bottom = 约原高度的 **60%～80%**  
- feathering 可 0 或很小  

输出的 IMAGE 就是「上半有人、下面空白」的图。

### B2. 节点改动（相对文生图）

| 原节点 | 改法 |
|--------|------|
| `EmptySD3LatentImage` | **断开/不用** |
| 新增 `Load Image` | 选加高后的图（或接 Pad 的输出） |
| 新增 `VAE Encode` | IMAGE→VAE Encode；VAE 接你的 `qwen_image_vae` |
| `KSampler.latent_image` | 改接 **VAE Encode 的 LATENT** |
| `KSampler.denoise` | 先试 **0.45**，不行再 **0.55～0.65**（不要 1.0） |
| LoRA | 可先 **0.5～0.7**（全身阶段略降，减半身先验） |

连线关系：

```text
Load Image ──IMAGE──► VAE Encode ──LATENT──► KSampler.latent_image
Load VAE   ──VAE───► VAE Encode
                 └──────────────► VAE Decode（照旧）

Load Diffusion → LoRA → AuraFlow → KSampler.model
CLIP Text Encode → KSampler.positive
ConditioningZeroOut → KSampler.negative
```

尺寸：KSampler 跟着编码后的 latent 走，**不要再强制 EmptySD3 的 928×1664 另起一张空潜空间**（否则等于没垫图）。

### B3. 提示词（图生图专用，短）

正面：

```text
完整全身站立，从头到脚，双脚可见，青绿长袍下摆自然延伸，绣鞋，冷青远山，工笔平涂，天书奇谈美影风格，保持与参考图同一人物同一妆服，full body, feet visible
```

负面（若有框）：

```text
半身, 中近景, 缺脚, 裁切双脚, half body, cropped legs, close-up, 另一张脸, 换装
```

### B4. 参数怎么拧

| 现象 | 调法 |
|------|------|
| 几乎不变、仍无腿 | denoise ↑ 到 0.55～0.65；确认画布下方真有大块空白 |
| 脸崩、妆漂 | denoise ↓ 到 0.35～0.45；LoRA 略降；提示词少写五官 |
| 下半身风格不接 | 空白选区略重叠原袍摆；prompt 强调「下摆自然延伸」 |

**有 Mask 更好：** 只蒙下方空白再采样（上半身 denoise 等效为 0）。没有 Mask 节点就用整图低 denoise + 大留白，多抽选优。
