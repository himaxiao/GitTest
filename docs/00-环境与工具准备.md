# 阶段 0：环境与工具准备（必做）

目标：在开始写剧本、跑图之前，把 **硬件、软件、账号、模型、目录、素材库** 一次装齐并验收通过。

风格目标：**《天书奇谈》** 式国风奇幻 —— 水墨晕染、工笔勾线、妖异仙气、略带怪诞与民间志怪气质（聊斋）。

---

## 0.1 硬件最低建议

| 用途 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 仅用在线 AI（Midjourney / 可灵 / Runway） | 任意能上网电脑 + 稳定宽带 | 16GB 内存，SSD |
| 本机 Stable Diffusion / ComfyUI | NVIDIA 显卡 **8GB 显存** | **12–24GB 显存**（RTX 4070 / 4080 / 4090） |
| 剪辑 1080p 短片 | 16GB 内存 | 32GB 内存 + SSD |
| 存储 | 预留 **100GB+** | 预留 **300GB+**（素材与多版本） |

### 当前项目硬件（已锁定）

- **GPU：RTX 4080 SUPER 16GB**
- **路线：本机 ComfyUI 出图为主 + 可灵图生视频 + 本机剪辑**
- **专项手册：[03-RTX4080S本机安装手册.md](03-RTX4080S本机安装手册.md)**（按这篇装即可）

> 没有 NVIDIA 显卡：优先走「在线生成 + 本机剪辑」路线，不必强装 ComfyUI。  
> **有 4080S：不要走纯云端**，静帧与角色一致性应在本机控死。

**本阶段验收：**

- [x] 明确路线：**本机 + 云端混合（4080S）**
- [ ] 磁盘预留足够空间（建议模型盘 150–250GB），并建好本仓库对应文件夹

## 0.2 必装软件总览（按优先级）

### A. 核心必备（先装）

| 软件 | 用途 | 平台 | 下载 |
|------|------|------|------|
| **Chrome / Edge** | 访问各类 AI 网页工具 | Win/Mac | 系统自带或官网 |
| **剪映专业版** 或 **DaVinci Resolve** | 剪辑、调色、字幕、成片 | Win/Mac | 见下方下载清单 |
| **Audacity** 或 **Adobe Audition** | 配音降噪、音效整理 | Win/Mac | 见下载清单 |
| **FFmpeg** | 转码、抽帧、合并音视频 | Win/Mac/Linux | https://ffmpeg.org |
| **Git** | 同步本工程文档与提示词 | Win/Mac/Linux | https://git-scm.com |
| **7-Zip / Bandizip** | 解压模型与素材包 | Win | 常见压缩软件 |

### B. 图像生成（二选一主路线）

| 路线 | 工具 | 适合谁 | 备注 |
|------|------|--------|------|
| **云端优先** | Midjourney / 即梦 / Liblib / 通义万相 | 无显卡 | 出图快，一致性较弱 |
| **本机可控（本项目采用）** | **ComfyUI** + SDXL / Flux | **4080S 等 NVIDIA 显卡** | 角色一致性、批量、可控性更强 |

**本项目建议：** 本机 ComfyUI 负责定妆/分镜/精修；可灵负责镜头运动；剪映/Resolve 成片。详细步骤见 `03-RTX4080S本机安装手册.md`。

### C. 动画 / 图生视频

| 工具 | 用途 | 说明 |
|------|------|------|
| **可灵 Kling** | 图生视频、镜头运动 | 国风短片常用，角色一致性相对好 |
| **Runway Gen-3 / Aleph** | 图生视频、运镜 | 运镜自然，适合氛围镜头 |
| **Luma Dream Machine** | 氛围、奇幻镜头 | 光影表现好 |
| **海螺 / 即梦视频** | 国内可用备选 | 按账号情况选用 |
| **CapCut / 剪映** 内置 AI 动效 | 轻量补镜头 | 仅作补充，不宜当主力 |

### D. 角色一致性与修图

| 工具 | 用途 |
|------|------|
| **Photoshop** 或 **Photopea**（免费网页） | 修脸、统一色调、拼分镜 |
| **Krita**（免费） | 手绘修线、补墨迹 |
| **IP-Adapter / InstantID / FaceID**（ComfyUI 插件） | 角色长相锁定 |
| **ControlNet**（ComfyUI） | 线稿、深度、姿态锁定 |

### E. 音频

| 工具 | 用途 |
|------|------|
| **ElevenLabs** 或 **微软/讯飞/海螺配音** | AI 旁白与角色声线 |
| **Suno** / **Udio** / **天工音乐** | AI 配乐（古风、志怪氛围） |
| **Freesound** / **爱给网** | 环境音、音效素材 |
| **Audacity** | 免费剪音频、降噪 |

## 0.5 剪辑与成片软件安装

### 方案 1：剪映专业版（最快上手，中文友好）

1. 下载「剪映专业版」（桌面端，不是仅手机 App）

3. 确认可导入 MP4、WAV、PNG

1. 官网下载 Free 版：https://www.blackmagicdesign.com/products/davinciresolve
2. 安装 Fusion / Fairlight 一并可用
3. 新建 HD 时间线，帧率与生成素材统一（建议 **24fps**，更有手绘片感）

## 0.8 提示词与测试出图（环境冒烟测试）

不要一上来做整部片子。先做 **冒烟测试**：

1. 用同一条提示词生成 **角色半身像** 3 张，选出 1 张定妆
2. 用同一角色参考生成 **同一人物不同角度** 2 张，检查一致性
3. 用定妆图做 **图生视频** 3–5 秒（微风、烛火、衣袂）
4. 导入剪辑软件，加一段旁白测试音量

测试提示词可直接用：`prompts/00-冒烟测试.md`

**本阶段验收（最重要）：**

- [ ] 出图链路通
- [ ] 图生视频链路通
- [ ] 剪辑导出链路通
- [ ] 对「天书奇谈味」有一张自己满意的样张
