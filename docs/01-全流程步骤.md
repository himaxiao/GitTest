# 全流程步骤：从零到成片

前置条件：先完成 [`00-环境与工具准备.md`](00-环境与工具准备.md) 的全部验收项。

目标成片：**60–90 秒** 国风 / 聊斋短片，风格接近《天书奇谈》。

---

## 总览（8 步）

```
1 故事核    →  2 风格圣经  →  3 角色场景设定
     ↓
4 分镜表    →  5 关键帧静帧 →  6 图生视频
     ↓
7 配音配乐  →  8 剪辑成片
```

---

## 步骤 1：定故事核（半天内完成）

写进 `01-script/故事核.md`，只回答四个问题：

1. **谁**：一个有缺陷或执念的人 / 妖（例如落魄书生、狐女、庙祝）
2. **要什么**：一个具体欲望（还魂、报仇、成仙、找回名字）
3. **障碍**：天规、旧债、谎言、妖物交易
4. **结局味道**：苍凉、警世、荒诞、一丝温暖（选一个主味）

《天书奇谈》可借鉴点：

- 民间志怪逻辑 > 甜宠古风
- 妖物有「人味」与「怪味」并存
- 留白：不必解释所有法术规则

**产出：** 一句话 logline + 三段式大纲（起 / 承转 / 合）

---

## 步骤 2：写风格圣经

填写 [`02-天书奇谈风格圣经.md`](02-天书奇谈风格圣经.md)，并在 `refs/` 放满参考图。

必须定死：

- 线条：细硬勾线 or 水墨散锋？
- 色彩：冷青夜色 + 烛金，避免粉嫩古风
- 运动：慢、沉、衣袂与烟雾为主，少炫技运镜
- 禁忌：现代 UI 感、赛博霓虹、三渲二网感、过度美颜

**产出：** 风格圣经 v1 + 参考看板

---

## 步骤 3：角色 / 场景 / 道具设定

目录：`02-visual-bible/`

每个主角至少：

- 定妆正面半身
- 侧面 / 3/4 侧
- 全身（含服饰关键道具）
- 一张「情绪表情」

每个主场景至少：

- 白天或常态
- 夜景 / 妖气版本
- 一个特写材质（砖、木、雾、水墨山）

**工具：** Midjourney / 即梦 / Liblib / ComfyUI  
**关键：** 用同一张定妆图做参考（垫图 / IP-Adapter），锁住脸与服饰。

**产出：** 角色卡 + 场景卡，文件名带 `v01`

---

## 步骤 4：分镜表

目录：`03-storyboard/`  
模板：`03-storyboard/分镜表模板.md`

建议镜头数：

- 60 秒片：约 **12–18** 个镜头
- 90 秒片：约 **18–25** 个镜头

每个镜头写清：

| 字段 | 例 |
|------|----|
| 镜号 | S01-L03 |
| 景别 | 全景 / 中景 / 特写 |
| 时长 | 3–5 秒 |
| 画面 | 荒庙门内，狐女背对烛火 |
| 动作 | 回头，耳尖微动 |
| 声音 | 雨声 + 旁白一句 |
| 生成方式 | 图生视频 / 静帧推拉 |

**产出：** 分镜表 +（可选）手绘或 AI 小分镜图

---

## 步骤 5：关键帧静帧（先静后动）

目录：`04-keyframes/`

原则：

1. **先出静帧，再动画** —— 静帧不过关不要烧视频点数
2. 每镜 1 张主关键帧；复杂动作可加起止帧
3. 统一画幅 **16:9**，分辨率至少 **1280×720**（推荐 1920×1080）
4. 同一场戏保持同一色板与光源方向

提示词模板见：`prompts/01-角色场景.md`、`prompts/02-分镜关键帧.md`

**产出：** 按镜号命名的关键帧序列

---

## 步骤 6：图生视频

目录：`05-animation/`

推荐参数习惯：

- 时长：**4–5 秒** 一段，剪辑时再衔接
- 运动：**微动优先**（风、烛火、烟雾、眨眼、衣角）
- 少用剧烈转身 / 快速跑动（易崩脸）
- 运镜：缓慢推 / 轻微横移 / 固定机位

工具优先级建议：

1. 可灵（角色相对稳）
2. 即梦视频 / Runway
3. 不行就「多张静帧 + 剪映动态变焦」救场

**产出：** `动画_Sxx_Lxx_工具_v01.mp4`

---

## 步骤 7：配音、音效、配乐

目录：`06-audio/`

分层：

1. **旁白 / 对白**（先定声线，再批量生成）
2. **环境底噪**（雨、风、夜虫、庙宇空腔回声）
3. **点状音效**（脚步、门轴、烛火噼啪、狐狸鸣）
4. **配乐**（低沉古风，少歌词；或纯器乐）

音量经验：

- 对白最清晰
- 配乐压在对白下（大约对白的 20–35%）
- 环境声很轻，用来「托住空间」

**产出：** `旁白/` `音效/` `配乐/` 三个子文件夹素材

---

## 步骤 8：剪辑与成片

目录：`07-edit/` 工程，`08-export/` 成片

剪辑顺序：

1. 按分镜铺视频轨（画面锁叙事）
2. 对齐旁白
3. 加环境声与音效
4. 铺配乐，闪避对白
5. 统一调色（偏冷青，烛火处留暖）
6. 字幕（若有）：古拙、少花字
7. 片头片尾极简（片名 + 一句引语即可）

导出建议：

- 1080p，H.264
- 24fps 或 25fps（全片统一）
- 备份工程与 `v01/v02` 成片

**产出：** `08-export/成片_标题_1080p_v01.mp4`

## 质量门禁（每阶段过关再往下）

| 阶段 | 过关标准 |
|------|----------|
| 故事核 | 陌生人 10 秒能听懂冲突 |
| 风格 | 去掉 Logo 仍像「天书奇谈气质」而非通用古风 |
| 设定 | 主角三张图一看是同一人 |
| 分镜 | 无声播放也能看懂事件顺序 |
| 关键帧 | 单帧可当插画，光色统一 |
| 动画 | 脸不崩、动作服务情绪 |
| 声音 | 闭眼只听声音也有氛围 |
| 成片 | 60–90 秒内有完整情绪弧 |
