## 2. 流程能不能还原？——能还原到「阶段」，难还原到「精确按钮」

### 高置信：标准国风 AI 短片流水线（与同赛道一致）

和市面「聊斋 / 天书奇谭风」账号高度同构，几乎一定是这 6 步：

```
① 选篇/改编文案
    ↓
② 写成适合短视频的剧本（旁白驱动，少对口型长对白）
    ↓
③ 做「资产」：角色定妆、场景、道具（统一风格参考）
    ↓
④ 按分镜批量出关键帧 / 镜头图
    ↓
⑤ 图生视频：每段数秒～十余秒，再拼接
    ↓
⑥ 旁白 + 配乐 + 音效 + 剪辑成片（达芬奇/PR/剪映等）
```

第三方以「古卷残灯同款」名义售卖的课，目录也基本是这套：

`制作流程 → 文案来源 → 文案转剧本 → 资产生成 → 视频生成`

这与你仓库里的 `docs/01-全流程步骤.md` **同构**。

### 中置信：视频生成主力很可能是「即梦 Seedance」系

多家「同款课」材料反复出现配套包名称，例如：

- `天书奇谭风格` 参考图包  
- `资产提示词包`  
- **`Seedance 2.0` 视频提示词包**（常见写法：**16:9、约 10 秒一段**）

**Seedance** = 字节跳动视频模型，消费级入口主要是 **即梦 AI**（也出现在豆包等）。

因此：**对标「古卷残灯类」成片，优先准备即梦 + Seedance，而不是只盯可灵/海螺。**  
可灵/海螺仍可作备选或局部镜头。

> 注意：卖课站点不等于 UP 官方声明；但「Seedance + 天书奇谭资产包」在该赛道出现频率极高，作为工作假设合理。

### 低置信 / 未证实

| 猜测 | 状态 |
|------|------|
| 是否用 ComfyUI / Midjourney 出静帧 | **未证实**；也可用即梦生图、Liblib、MJ |

## 3. 必要工具清单（对标该赛道 · 可执行版）

### A. 几乎必用

| 环节 | 工具 | 说明 |
|------|------|------|
| 故事改编 | 文档 +（可选）大模型改写 | 聊斋篇目 → 短视频结构、旁白稿 |
| 风格锚点 | 《天书奇谭》等参考图板 | 与古卷残灯赛道一致的核心辨识度 |
| 角色/场景资产 | **即梦生图** 和/或 **ComfyUI(SDXL)** | 先定妆、再分镜；强调一致性 |
| 图生视频 | **即梦 Seedance（2.0）** | 同赛道课最常点名；建议 16:9、短镜头拼接 |
| 剪辑 | **达芬奇 / PR**（你已有） | 多段 AI 视频 + 旁白时间线 |
| 旁白 | TTS 或人声 | 长片以旁白叙事为主 |
| 配乐音效 | 音乐 AI / 素材站 | 笛箫鼓、雨夜、空庙等 |

### B. 强烈建议（提升稳定）

| 工具 | 用途 |
|------|------|
| 角色三视图 / 定妆锚点图 | 每镜垫图，防崩脸 |
| 分镜表（镜号、时长、旁白句） | 10 分钟片 ≈ 几十上百段短视频 |
| PureRef / 本地 refs 文件夹 | 锁色与造型 |

### C. 可选（你已在准备的）

| 工具 | 何时用 |
|------|--------|
| **可灵 / 海螺** | Seedance 某镜不行时换引擎；或动作更稳的镜头 |
| **ComfyUI 新版** | 资产与关键帧要更可控、批量、锁脸时（IP-Adapter） |
| AnimateDiff 本机 | 一般不必；他们这种成片更依赖云端视频模型 |

## 4. 和他们「长片」匹配的制作节奏（反推）

以 **10 分钟** 为例（约数）：

| 步骤 | 经验量级 |
|------|----------|
| 旁白字数 | 约 1500–2500 字量级（视语速） |
| 视频段数 | 常要 **40–100+** 段短镜头（每段 3–10 秒） |
| 资产 | 主角 1–3 人定妆 + 每场主场景 2–5 张 |
| 耗时瓶颈 | 不是「会不会用 AI」，而是 **分镜管理、返修崩镜、声音剪辑** |

所以：工具可以很简单（即梦 + 剪辑 + TTS），**工程管理**才是他们能日更/周更系列的关键。

## 5. 对你当前配置的对标建议

你已有：**4080S + 新 ComfyUI + 可灵/海螺网页 + 达芬奇/PR**

若要更贴近「古卷残灯赛道」，请 **补这一块**：

1. **即梦 AI** 网页：https://jimeng.jianying.com/ （或以官方当前入口为准）  
2. 使用其中的 **Seedance** 视频能力（图生视频 / 参考图）  
3. 建立「天书奇谭」refs + 角色资产包（与本仓库 `refs/`、`02-visual-bible/` 一致）  
4. 视频按 **8–10 秒一段** 生成，再进达芬奇拼接  
5. ComfyUI：专心做出 **比即梦更稳的定妆/分镜静帧**，再喂给 Seedance/可灵/海螺

**最小对标栈：**

```
聊斋改编文案
  → ComfyUI 或即梦：角色/场景资产（天书奇谭风）
  → 即梦 Seedance：分段图生视频
  → TTS + 配乐
  → 达芬奇/PR 成片
```

可灵、海螺 = 并行备选，不是这条赛道的唯一解。
