# 本目录用途

## 01-script
剧本、故事核、对白表。

## 02-visual-bible
角色定妆、锚点、训练净板、场景板、角色包。见该目录 README。

## 03-storyboard
分镜表与分镜图。

## 04-keyframes
每个镜头的主关键帧静帧（先过审再动画）。

## 05-animation
图生视频导出的镜头片段。

## 06-audio
建议子目录：`旁白/` `对白/` `音效/` `配乐/`

## 07-edit
剪映 / Resolve 工程文件与缓存说明。

## 08-export
成片与送审版本，保留 v01/v02。

## control
Pose / Depth / 表情驱动源（远期 Phase C/D）。

## datasets
风格 LoRA / 角色 LoRA 训练集说明与空位。

## workflows
导出的 ComfyUI 工作流 JSON。

## refs
风格参考图（学习用）。请自行放入参考，注意版权边界。

## prompts
可复用提示词。

## tools
下载清单、迁移脚本、辅助工具。

## docs
制作文档；远期架构见 `14-远期管线架构总纲.md`。
