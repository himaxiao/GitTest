# 《天书奇谈》向 · 风格圣经（模板）

> 先填这个文件，再大规模出图。风格漂移往往不是模型不行，而是圣经没定死。

## 1. 一句话风格

用一句话描述你的片子（示例，请改成你的）：

> 冷青夜色里的民间志怪：工笔勾线的人物走在水墨晕开的山与雾中，妖异而克制，像《天书奇谈》遇上聊斋残卷。

## 2. 视觉支柱（只留 3 条）

1. **线条：** （例：清朗勾线，衣纹有力，面部克制不网感）
2. **墨色 / 色彩：** （例：墨青、石绿、烛火暖金；忌粉紫甜宠）
3. **气质：** （例：怪诞、寂静、宿命感；少卖萌）

## 3. 色彩板

| 角色 | 色值感受 | 用在哪 |
|------|----------|--------|
| 主背景 | 墨青 / 灰蓝夜空 | 外景夜、山林 |
| 辅助 | 石绿、花青 | 苔藓、衣缘、妖气 |
| 高光 | 烛金 / 纸灯暖黄 | 人脸、火焰、符纸 |
| 禁忌色 | 霓虹紫、樱花粉、赛博青 | 一律不用 |

## 4. 角色造型规则

- 五官：偏古典绘画，不要过度磨皮美颜
- 服饰：可识别时代感（明式 / 民俗戏服感），避免现代汉服网红款堆砌
- 妖物：保留「不像人」的局部（耳、尾、瞳、骨 dens）
- 比例：可轻微夸张，服务性格，不追写实摄影

## 5. 场景规则

- 多「空」：留白、雾、远山层染
- 建筑：破庙、牌坊、竹林、古桥、书斋
- 天气：夜雨、薄雾、阴雪优先于大晴天
- 光源：烛、月、磷火、雷光 —— 同时最多两种主光

## 6. 运动与剪辑气质

- 镜头运动慢，像在「看画」
- 动作幅度小：回头、举灯、衣袂、烟缕
- 转场：叠化、墨晕、硬切；少用现代闪白炫光
- 帧率感：偏 24fps，略带传统动画的顿挫亦可

## 7. 声音气质

- 配乐：笛、箫、古琴、低沉鼓；少流行唱腔
- 环境：雨、风入林、空庙回声
- 对白：文言白话夹杂可，但忌油腻网感台词

## 8. 提示词关键词库（可直接复制）

**正向常用：**

```
Chinese ink wash animation, classic Shanghai animation aesthetic,
fine line illustration, gongbi portrait, mystical folklore,
cold cyan night, candlelight gold, foggy mountains, eerie yet poetic,
inspired by traditional Chinese animated film Tales of the Heavenly Book,
Liaozhai supernatural atmosphere, painterly, film still
```

**中文正向：**

```
中国水墨动画，上海美影气质，工笔人物，细线勾勒，
聊斋志怪氛围，冷青夜色，烛火暖金，远山云雾，
奇幻而克制，画面如插画，电影静帧
```

**负向常用：**

```
photorealistic, 3d render, anime idol face, cute chibi,
neon cyberpunk, pink pastel, modern city, blurry, extra fingers,
western fantasy armor, Disney style, plastic skin
```

**中文负向：**

```
照片级写实，三渲二，网红脸，Q版萌，赛博霓虹，
粉紫甜宠，现代都市，模糊，手指畸形，迪士尼风
```
