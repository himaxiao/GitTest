# 本地视频链路（4080 SUPER 16GB）

目标：少花/不花即梦·可灵·海螺积分，用 **ComfyUI 本机图生视频** 打通  
「定妆静帧 → 短视频 → 达芬奇」。

显卡：**RTX 4080 SUPER 16GB**（已实测社区可跑通同类配置）

---

## 预期（先说清）

| | 云端（可灵/即梦） | 本地 Wan2.2-5B |
|--|------------------|----------------|
| 费用 | 按量贵 | 电费为主 |
| 运动质量 | 通常更稳、更强 | 够用；复杂动作易糊 |
| 适合 | 成片关键镜头 | **微动、试流程、大量草稿** |
| 你的短片 | 可作后期升级 | **现在打通用这个** |

本地先追求：**烛火摇、衣袂微动、4–5 秒、脸不太崩**。

---

## 推荐组合（16GB）

| 优先级 | 模型 | 用途 |
|--------|------|------|
| ★★★ 主力 | **Wan 2.2 TI2V-5B** | 文生视频 + **图生视频** 同一套，4080S 合适 |
| ★★ 备选 | **LTX-Video 2B** | 更快更轻，长了易崩 |
| ✗ 暂缓 | Hunyuan 大杯 / Wan 14B 满血 | 16GB 吃力或要猛 offload |

磁盘大约再留 **20–30GB**（Wan5B 套件约 17GB）。

---

## 安装步骤

### 1. 更新 ComfyUI

跑便携包里的：

```text
update\update_comfyui.bat
```

需新到自带 **Wan 2.2** 模板。

### 2. 打开模板（不要用 API）

1. 左侧 **Templates**  
2. 筛 **Node graph** / Video  
3. 搜：`Wan2.2` / `Wan 2.2` / `5B`  
4. 打开带 **Image to Video / 图生视频 / TI2V** 的本地模板  

官方说明可参考：ComfyUI 文档里的 Wan2.2 教程。

### 3. 按模板 Model links 下载到对应目录

常见放置（以模板左栏为准）：

```text
ComfyUI/models/
  diffusion_models/   ← Wan2.2 TI2V-5B 权重
  text_encoders/      ← umt5_xxl_fp8…
  vae/                ← wan2.2_vae / wan_2.1_vae
```

国内可用 **hf-mirror.com** 镜像下 Hugging Face 文件。

### 4. 图生视频怎么用定妆照

1. 模板里找到 **Load Image**（没有就加一个）  
2. 上传主定妆 PNG  
3. 接到图生视频入口（首帧 / image）  
4. 提示词用微动版（少写版权作品名）：

```text
中国传统手绘动画风格，几乎固定机位，轻微缓慢推近，
烛火轻轻摇曳，轻微呼吸，发丝与衣袖微动，
表情安静，不转身，不走路，保持与参考图一致，
冷青夜色，远山，5秒
```

5. 建议分辨率先 **832×480** 或模板默认；时长先 **2–5 秒**  
6. Run → 输出在 `ComfyUI/output/`  

### 5. 进成片

把 mp4/webm 拷到：

```text
05-animation/动画_狐女烛火_Wan_v01.mp4
```

再拖进达芬奇。

---

## 显存小技巧（4080S）

- 先跑 **5B TI2V**，别一上来 14B  
- 出 OOM：降分辨率、减帧数、开模板自带的 offload  
- 要加快：以后再加 Lightning/LightX2V 类加速 LoRA（按模板说明）

---

## 和现有静帧链路的关系

```text
Qwen 国漫 + 美术电影 LoRA  → 定妆/关键帧（已通）
        ↓
Wan2.2-5B 图生视频（本地）→ 短镜头
        ↓
达芬奇/PR → 成片
```

云端只作以后「钱够了再精修关键镜头」的备选，不是现在必需。
