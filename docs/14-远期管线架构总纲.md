# 远期管线架构总纲（天书 / 聊斋系列）

> 定位：**严谨框架先立，细节分期实现。**  
> 本文是系列生产的「系统说明书」，不是本周操作手册。  
> 现阶段试片仍走：Qwen 静帧 → Wan2.2 微动 → 剪辑降帧；下文模块按阶段解锁。

---

## 0. 设计原则（不可破）

1. **解耦优于一次性生成**  
   身份 / 风格 / 构图 / 运动 / 光色 / 镜头分轨约束，禁止「一条长提示词包办」。
2. **锚点资产先于抽卡**  
   任何镜头的输入必须能追溯到：角色锚点、场景板、运动等级、验收标准。
3. **容错极低的东西单独造**  
   训练用底板 ≠ 镜头关键帧。干净三视图/局部特写进训练集；带烛火场景的进分镜库。
4. **一次只加一层控制**  
   新模块上线必须有「接入前基线 → 接入后验收」；失败可回滚到上一层。
5. **本地 4080S（16GB）为硬约束**  
   模块选型优先：显存可跑、可分时加载、可降级（无某节点时整条链仍可出试片）。

## 2. 分层控制模型（核心抽象）

对应 Substance / Shader Graph 思维：每层是「约束输入」，不是散文提示词。

```text
L0  风格层     Style LoRA / 风格圣经 / 禁用词表
L1  身份层     定妆锚点 / 角色 LoRA / IP-Adapter·Redux
L2  结构层     景别构图静帧 / LineArt·Depth·Pose ControlNet
L3  表演层     表情驱动（LivePortrait）/ 口型（后期）
L4  运动层     Wan / AnimateDiff + 运动白名单等级
L5  镜头层     静机位 → CameraCtrl → Depth 序列（由易到难）
L6  合成层     SAM2 分层 / 宣纸纹理 / 前后景合成
L7  成片层     降帧(8–12fps 观感) / 旁白 / 调色 / 导出
```

| 层 | 服务对象 | 主要失败模式 | 未就绪时的降级 |
|----|----------|--------------|----------------|
| L0 | 全片气质 | 3D 光影、写实皮肤 | 提示词禁令 + 美术电影 LoRA |
| L1 | 「谁」 | 换脸换装 | 定妆首帧垫图 |
| L2 | 「站哪、什么景别」 | 半身锁死、透视漂 | Qwen 重出关键帧 |
| L3 | 微表情 | 妆线崩 | 静脸 + 剪辑暗示 |
| L4 | 动什么 | 脸狰狞、空抖 | A 级仅烛火/雾 |
| L5 | 推拉摇 | 全图变形 | **固定机位** |
| L6 | 纸感统一 | 边毛、色不贴 | 成片统一 LUT/叠加 |
| L7 | 美影律动 | 过度丝滑 | 强制抽帧 |

## 3. 资产体系（AI 定妆 ≠ 传统设定）

### 3.1 两类资产必须分库

| 库 | 路径（规划） | 用途 | 要求 |
|----|--------------|------|------|
| **锚点库 Anchor** | `02-visual-bible/anchors/` | I2V 首帧、IP-Adapter | 可含场景光，但身份清晰 |
| **训练净板 Train-Clean** | `02-visual-bible/train-clean/` | 炼角色 LoRA | 纯色/简单底、无遮挡、正侧背、局部特写 |
| **场景板 Set** | `02-visual-bible/sets/` | 跨集复用环境 | 荒园门、书斋、窗烛等 |
| **镜头关键帧 KF** | `04-keyframes/` | 单集分镜 | 命名 `KF_Sxx_…` |
| **控制源 Control** | `control/` | Pose/Depth/表情驱动 | 与成片脱钩存放 |

### 3.2 角色包最小完备集（每主角一份）

```text
CHAR_<名>/
  anchors/     主定妆、¾、侧、全身母图
  train-clean/ 正、侧、背、脸特写、服饰特写（炼 LoRA 用）
  tags.md      锁定词与禁用词
  sheet.md     版本与验收记录
```

### 3.3 风格包（全系列一份）

```text
datasets/style-tianshu/
  raw/         合法学习用切片（自备，注意版权）
  captions/    标注
  NOTES.md     训练配置与版本
```

## 5. 逻辑数据流（目标态）

```text
剧本/旁白
   ↓
分镜表（每镜：锚点、运动等级、时长、音频）
   ↓
L0+L1 出/选 关键帧静帧（Qwen ± LoRA ± IP-Adapter）
   ↓
[可选 L2] ControlNet 锁结构重绘
   ↓
L4 I2V（Wan；首帧=关键帧；白名单运动）
   ↓
[可选 L3] 表情后处理（LivePortrait）
   ↓
[可选 L6] SAM2 + 质感合成
   ↓
L7 时间线：降帧、叠化、旁白、成片
```

试片态允许短路：`分镜 → Qwen 关键帧 → Wan → L7`。

## 6. 运动等级表（全系列沿用）

| 等级 | 允许 | 禁止 | 典型镜头 |
|------|------|------|----------|
| **A** | 烛火、雾、极轻衣袂 | 转头、走、推镜、口型 | S02/S03 试片 |
| **B** | 缓慢转头 ≤15°、抬手 | 快走、多人物交互 | 后续 |
| **C** | 骨骼驱动走位、拂袖 | 无 Pose 的复杂互博 | 有 DWPose 后 |

每镜分镜表必须标注等级；生成提示词只写该等级白名单。
