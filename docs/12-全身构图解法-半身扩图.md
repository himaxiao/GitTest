# 全身出不来：根因与一次做完的解法

> 结论先行：**不要再靠「多写全身提示词」硬抽。**  
> 美术电影 LoRA + 角色细节会把构图锁在半身；彻底办法是 **半身定妆 → 向下扩图补腿**。

---

## 1. 问题到底出在哪

| 误判 | 实情 |
|------|------|
| 「提示词没生效 / 分辨率不对」 | 提示词有进模型，但 **权重大不过 LoRA/数据先验** |
| 「竖图就能出全身」 | 竖图只是更容易，**不保证**；你这张已是竖图，仍裁在大腿 |
| 「再改几句提示词就行」 | 在 LoRA≈0.8 + 长妆服描述下，成功率长期很低 |

更具体：

1. **美术电影 / 角色类 LoRA** 训练集大量是半身、中近景美人图 → 构图先验极强  
2. 提示词里 **脸、花钿、领口、烛火、电影静帧** 会把注意力拉到上半身  
3. Qwen 文生图对「景别」服从度本来弱于「主体好看」  
4. 词义：你要的是 **全身（head to toe）**，不是电影术语里的「全景空镜」

所以：**不是你操作低级，是这条链路用纯文生图锁全身不合适。**

---

## 2. 彻底解法（只走这一条）

```text
已有满意的半身定妆
    → 画布向下加高（脚下留空）
    → 只重绘空白区域（扩图 / outpaint）
    → 得到真全身
    → 需要横构图时再左右扩到 1664×928
```

上半身（脸、妆、衣）**不再重新抽卡**，避免又漂。

### 本机最快（推荐先做）

用 **Photoshop 生成式填充** 或 **即梦/其它扩图** 即可：

1. 打开当前这张竖图半身  
2. 画布 **只加高下方**（例如总高度变为原来的 1.5～1.8 倍，宽度不变）  
3. 人物锚在上方，脚下是空白  
4. 选中空白 → 生成式填充 / 扩图，提示只写下肢，例如：

```text
延续同一青绿长袍下摆与裙褶，露出鞋履与站立地面，工笔平涂，天书奇谈风格，与上半身同一人物同一服装，full body lower half, feet visible, no cropping
```

5. 导出：`CHAR_青凤_全身_竖_v01.png`  
6. 若要镜头横版：再 **左右扩** 到 1664×928（同样只补背景，人不动）

### ComfyUI 等价（有节点再上）

同一逻辑：`Load Image` → `ImagePad`/`Pad For Outpaint`（只 pad bottom）→ mask 底部 → `VAE Encode` → `KSampler`（denoise 约 **0.45–0.65**，只影响扩出区）→ 解码保存。  
**不要**对整张图 denoise=1 重抽。

## 3. 如果仍想文生图赌全身（不推荐当主路径）

仅作备选，且接受仍可能失败：

| 项 | 改法 |
|----|------|
| LoRA | **0.25～0.4**（半身先验的主凶） |
| 提示词结构 | **构图句放最前并重复 2 次**，妆服锁定段缩短 |
| 删除/弱化 | `电影静帧`、大段五官描写、烛火特写 |
| 负面必加 | `half body, close-up, portrait, cropped legs, upper body, cut off feet, 半身, 中近景, 缺脚, 裁切` |
| 尺寸 | 保持竖图 `928×1664` 或更瘦长 |

示例（短构图优先）：

```text
full body, head to toe, entire figure, feet visible, standing, character small, vertical full body shot, 全身站立从头到脚，脚完全可见，
聊斋狐女，青绿袍，紫领白锯齿，白绦红结，额心四点红花钿，天书奇谈平涂
```

即使这样，**仍可能半身** → 立刻停，回到第 2 节扩图。

---

## 4. 和系列资产怎么挂钩（避免再耗时间）

| 资产 | 怎么来 | 用途 |
|------|--------|------|
| 半身主定妆 | 文生图抽卡（你已有） | 锁脸妆服 |
| 全身母图 | **半身向下扩** | 服饰全貌、站姿 |
| 横构图镜头帧 | 全身左右扩 / 或半身直接用 | S01–S04 / I2V |

**规则：脸和衣服以半身定妆为真；全身只负责“补全下半身”，不再重新发明妆容。**

---

## 5. 停止条件

- 再抽 2 次文生图仍无脚 → **禁止继续文生图赌全身**  
- 改用当前半身 **向下扩图**，当天必须出一张脚在画内的全身母图  

这不是优化空间问题，是 **方法换轨**。
