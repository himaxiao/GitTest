# 本地动画/漫剧：从试错到稳定产出

> 目的：结束「每个模板都试一下」的漂流状态，进入 **有门禁、有节奏、可复盘** 的生产。  
> 前提：4080S + Comfy（Qwen 静帧 + Wan2.2 微动）+ 剪辑；云端仅作点缀。  
> 配套：`docs/14-远期管线架构总纲.md`（远期模块）、本文件（**眼下怎么干活**）。

---

## 0. 先承认的现实（用来停焦虑）

1. **AI 默认不可控**；可控性来自你加的约束层，不是来自换模板运气。  
2. **一次只稳一条链路**。同时开 Qwen 模板、Wan 模板、SDXL ControlNet、即梦，只会让失败原因无法归因。  
3. **试片 ≠ 连载**。先有一条 40s 可验收成片，再谈漫剧集产能。  
4. 感觉「总不听话」时，优先查：**有没有跳过门禁**，而不是再下一个工作流。

---

## 1. 唯一主链路（冻结 30 天）

```text
剧本/旁白（固定）
  → 分镜表（每镜：时长、运动等级、首帧来源）
  → Qwen 出/选定妆与关键帧
  → Wan I2V（A 级微动白名单）
  → 剪辑：拼接 + 降帧观感 + 旁白
  → 导出试片 → 复盘表
```

**30 天内禁止：**

- 为「更好效果」频繁换底模全家桶  
- 未过试片验收就开炼角色 LoRA / 上 Blender Depth  
- 同一问题连换 3 个模板而不改约束（景别/运动/首帧）

允许的支线（每次只开一条，且写进复盘）：补关键帧构图、降 denoise、收紧运动提示词。

## 2. 门禁制（不通过不得进入下一阶段）

### Gate 0 · 故事可拍（半日）

- [ ] 总时长 ≤ 50s 或单集镜数 ≤ 8  
- [ ] 旁白定稿（可念完卡进镜头）  
- [ ] 分镜表填完：镜号 / 景别 / 秒数 / **运动等级 A/B/C** / 首帧文件名  

**不通过表现：** 边出图边改剧情。

### Gate 1 · 身份锚点（1～2 日）

- [ ] 主定妆 1 张（脸+妆服可复述）  
- [ ] 全身或半身母图 1 张（服饰完整）  
- [ ] `tags.md` 锁定词固定，全片复制，禁止每镜重写人设  

**不通过表现：** 每镜「换一套提示词碰运气锁脸」。

### Gate 2 · 关键帧可剪（2～4 日）

- [ ] 每镜 1 张过审关键帧，命名 `KF_Sxx_…`  
- [ ] 相邻镜色调/妆服不跳戏（七成像即可）  
- [ ] 无「再抽二十张碰构图」——每镜 **最多 4 张选 1**，超限就改提示词结构或景别，不空耗  

**不通过表现：** 关键帧未齐就进 Wan。

### Gate 3 · 视频可接（按镜）

- [ ] 仅使用 Gate2 的关键帧作 I2V 首帧  
- [ ] 运动严格按分镜等级（试片默认 **只开 A：烛火/雾**）  
- [ ] 每镜最多 **3 次** 生成；3 次仍崩 → 降运动或重做关键帧，不换视频大模型  

**不通过表现：** 提示词里写「转头走路推镜」却怪模型崩脸。

### Gate 4 · 成片可看（半日）

- [ ] 时间线按镜序；叠化克制  
- [ ] 旁白对齐；可降帧到 8～12fps 观感（美影感）  
- [ ] 导出一版，填复盘表（见下）  

**试片 DoD：** 观众 40s 内能看懂「荒园遇狐女」，脸不狰狞，总时长达标。

## 3. 每周节奏（个人产能模板）

以「有工作日晚上 + 周末」为例，可按比例缩放。

| 时段 | 固定任务 | 禁止 |
|------|----------|------|
| 周一 | 只改分镜表/旁白，不出图 | 开新工作流 |
| 周二～三 | 只出/修关键帧（Gate2） | 进 Wan |
| 周四～五 | 只跑 I2V（Gate3） | 改人设提示词 |
| 周六 | 剪辑 + 导出 | 新专题实验 |
| 周日 | **复盘 30 分钟** + 下周日计划 | 大改栈 |

原则：**一天一种作业类型**，大脑和节点图都保持单一上下文。

## 5. 复盘表（每周日必填）

| 问题 | 归因（只勾一个主因） | 下周动作（一条） |
|------|----------------------|------------------|
| 脸漂 | 锁定词不统一 / 关键帧差 / I2V 运动过大 | |
| 半身出不来 | 文生图硬抽 / 应用扩图 | |
| 视频静或崩 | 提示词越权 / 缺首帧锚 | |
| 环境跳 | 无场景板 / 每镜重抽场景 | |
| 耗时爆炸 | 无门禁、同日多任务 | |

**归因禁句：**「AI 不行」「再换个模板试试」（除非复盘写明：旧链路已门禁失败）。

## 6. 「难控」时的标准处置（决策树）

```text
效果不对
  ├─ 人设不对 → 回 Gate1，改锁定词/定妆，不改视频模型
  ├─ 构图不对 → 回 Gate2，改景别句或扩图，不加深运动
  ├─ 会动但崩 → Gate3：减运动到 A；仍崩 → 换关键帧
  ├─ 完全不动 → 只加强一个物理运动（烛火）；禁止同时加运镜
  └─ 流程混乱 → 停产 1 天，只整理分镜表与文件命名
```

## 10. 效率指标（用来判断「进入稳定产出」）

连续两周达到即可自称稳定阶段：

- 关键帧：平均每镜 ≤ 4 次出图出 1 张过审  
- 视频：平均每镜 ≤ 3 次 I2V 出 1 条可接  
- 周产出：≥ 1 条可发布试片 **或** ≥ 4 镜过 Gate3  
- 零「本周又换了主工作流」  

未达标 → 收紧运动与门禁，不增加工具。
