# 角色 / 场景提示词模板

## 角色三视图提示词骨架

```
[角色身份], [年龄气质], [服饰关键道具], [发型],
front view character design, consistent design sheet,
Chinese gongbi linework, ink wash animation aesthetic,
Tales of the Heavenly Book style, clean background, 16:9
```

例：

```
A poor Ming-dynasty scholar with worn blue robe and old book,
thin face, restrained expression, front view character sheet,
gongbi lines, Shanghai classic animation look, fog gray background
```

## 场景提示词骨架

```
[地点], [时间天气], [主光源], [气氛形容词],
Chinese ink wash animated film background art,
layered mountains, painterly, Tales of the Heavenly Book mood, wide shot
```

## 一致性技巧

1. 固定一段「风格尾句」全片复用（见风格圣经第 8 节）
2. 永远垫入定妆图作参考
3. 改镜头时先改「动作/景别」，少改「身份/服饰」描述
4. 出图后立刻改名归档，不要堆在下载文件夹
