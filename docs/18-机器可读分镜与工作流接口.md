# 机器可读分镜：让 AI 在工作流里真正用上分镜

> 目标：分镜不只是你「看得懂」，而是 **节点图能按字段执行**。  
> AI 并不会像导演那样「理解故事」；它只吃 **结构化条件**（图、词、数值、路径）。  
> 因此：把分镜写成 **Shot Card（镜头卡）**，每张卡 = 下游一次生成的全部输入。

---

## 1. 「AI 理解分镜」实际指什么

| 误解 | 实情 |
|------|------|
| 喂一篇分镜散文，模型就按戏拍 | 模型不读戏剧逻辑 |
| 一张分镜拼贴图 = 全片记忆 | 单次生成通常只强依赖 **当前首帧 + 当前提示词** |
| 工作流会自动懂镜号 | 除非你把镜号映射成 **文件路径 / 开关 / 参数** |

**可行定义：**  
对每一镜，工作流能自动或半自动拿到：

1. `first_frame` 图像路径  
2. `positive` / `negative` 提示词（已拼好）  
3. `motion_allowed` 白名单句  
4. 分辨率、帧数、denoise 等数值  
5. 产出文件名规则  

做不到这 5 项 = 分镜对 AI **尚未生效**。

## 2. 双文档制（人读 + 机读）

```text
03-storyboard/
  分镜表_青凤_v01.md          ← 人读总览、排期、状态
  shots/
    S01.json                 ← 机读镜头卡（工作流真输入）
    S02.json
    S03.json
    S04.json
```

- 改剧情、排期 → 改 Markdown 表  
- 点 Queue 前 → **以 JSON 为准** 填进节点（或日后脚本注入）  
- 表与 JSON 冲突时，**以 JSON 为执行源**，改完再同步回表

## 3. 镜头卡 Schema（字段 = 节点口）

```json
{
  "shot_id": "S01",
  "version": "v01",
  "duration_sec": 8,
  "aspect": "16:9",
  "gate": "ready_for_i2v",

  "identity_lock": "（固定身份锁定段，全片相同）",
  "style_lock": "（固定风格尾句，全片相同）",

  "framing": "wide shot, abandoned courtyard gate at night",
  "picture_one_liner": "cold cyan night, half-open wooden gate, misty mountains, no hero face",

  "motion_grade": "A",
  "motion_allowed": ["light mist", "almost static"],
  "motion_forbidden": ["camera shake", "character walk", "face close-up"],

  "still": {
    "mode": "t2i",
    "workflow": "qwen_t2i_handbuild",
    "positive": "【由 framing + picture + identity + style 拼接，见下节】",
    "negative": "photorealistic, 3d, text, watermark, extra limbs",
    "width": 1664,
    "height": 928,
    "batch": 4,
    "output_path": "04-keyframes/KF_S01_荒园夜门_v01.png"
  },

  "video": {
    "mode": "i2v",
    "workflow": "wan22_i2v_stable",
    "first_frame": "04-keyframes/KF_S01_荒园夜门_v01.png",
    "positive": "【keep reference + motion_allowed 句，禁止 forbidden】",
    "negative": "face morph, camera shake, warped limbs, sudden turn",
    "length_frames": 49,
    "width": 832,
    "height": 480,
    "max_tries": 3,
    "output_path": "05-animation/AN_S01_v01.mp4"
  },

  "audio": {
    "narration": "耿生夜过荒园，闻笑语切切。",
    "sfx": ["night wind"]
  }
}
```

### 字段 → Comfy 真实作用

| JSON 字段 | 进哪个节点/用途 |
|-----------|-----------------|
| `still.positive` | CLIP Text Encode（静帧） |
| `still.width/height` | EmptySD3LatentImage |
| `still.output_path` | 人工改名归档目标（日后可 Save 脚本化） |
| `video.first_frame` | Load Image → I2V 潜空间 |
| `video.positive` | Wan 正面提示 |
| `motion_forbidden` | 必须写进 negative 或正面「no …」 |
| `length_frames` | Wan 帧长控件 |
| `max_tries` | 生产门禁，不是模型参数 |

**没有映射到节点的字段，对 AI 等于不存在。**

---

## 4. 提示词必须「由卡拼出」，禁止自由发挥

### 静帧 positive 拼接公式

```text
{framing}, {picture_one_liner}, {identity_lock}, {style_lock}
```

### 视频 positive 拼接公式

```text
same image as first frame, keep face and costume unchanged,
{把 motion_allowed 写成英文/中文短句},
no camera move unless listed, 
禁止项：{motion_forbidden}
```

人只改 JSON 里的 `framing` / `picture_one_liner` / `motion_*`；  
**不**在 Comfy 文本框里临时写一篇新散文（否则机器卡失效）。

## 5. 工作流里「切实起作用」的三种落地级别

### L0 · 半自动（现在就能做）

1. 打开 `shots/S0x.json`  
2. 复制 `still.positive` → Qwen  
3. 出图归档到 `output_path`  
4. 复制 `video.*` → Wan，`Load Image` 指向 `first_frame`  
5. 勾掉 JSON 里未满足的 `gate`

### L1 · 清单驱动（稳产）

- 每日只处理 `gate == ready_for_still` 或 `ready_for_i2v` 的卡  
- 完成后改 `gate`：`done_still` / `done_i2v` / `failed_need_new_still`

### L2 · 脚本注入（以后）

- 小脚本读 JSON，写进 API / 预填 workflow 的 widget 默认值  
- 仍是同一 Schema；先有 L0/L1 才值得做 L2  

---

## 6. 怎样验收「AI 真的用上了分镜」

对任意一镜做盲测：

1. 隐藏聊天记录与脑内想法  
2. 只给执行者（或未来的你）`S0x.json`  
3. 按卡跑通静帧+视频  

若结果与卡上 `picture_one_liner` + `motion_allowed` 一致 → **分镜对 AI 生效**。  
若执行时还要「再解释一下这镜什么意思」→ 卡字段不够，补 `framing` / `motion_*` / `first_frame`，不要写长小说。

---

## 7. 与控制网/3D 的衔接（远期）

当上 Blender Depth 时，只在卡上 **加字段**，不推翻 Schema：

```json
"control": {
  "depth_frame": "control/depth/S01/depth_0001.png",
  "controlnet": "sdxl_depth",
  "strength": 0.7
}
```

工作流有 ControlNet 就读；没有就忽略。分镜仍然是同一套卡。
