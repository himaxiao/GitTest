# 稳定优先：纯本地视频配方（4080 SUPER）

原则：**不接云端**；先稳、再好看。  
静帧继续 Qwen；视频固定 **Wan 2.2 TI2V-5B**（你已下载的那套）。

16GB 上不要主攻 14B / Hunyuan 大杯——能出，但不「稳」。

---

## 总链路（固化）

```text
ComfyUI Qwen 定妆静帧
    → Wan2.2 TI2V-5B 图生视频（短、弱动、锁脸）
    → 多抽选片
    → 达芬奇拼接成片
```

---

## 一、只用这个视频模板

Templates → **Wan 2.2 5B Video Generation**（Node graph）

模型三件套必须是：

| 节点 | 文件 |
|------|------|
| Diffusion | `wan2.2_ti2v_5B_fp16.safetensors` |
| CLIP | `umt5_xxl_fp8_e4m3fn_scaled.safetensors` |
| VAE | `wan2.2_vae.safetensors` |

禁止再选：`wan2.1_t2v_14B…`、`wan2.1_vae`（你之前翻车就是串台了）。

图生视频：Ctrl+B 打开 **Load Image**，只垫**一张**主定妆。

---

## 二、稳定参数（先照抄，别猛拧）

| 项 | 稳定值 | 原因 |
|----|--------|------|
| 分辨率 | **832×480** | 脸更不容易糊崩 |
| 帧数 length | **49**（约 2–3 秒） | 越长短越容易五官漂移 |
| batch | **1** | — |
| 运动/strength/noise_aug | **偏低**（有则取小值） | 防狰狞 |
| CFG | **3.5～4** | 过高易毁脸 |
| steps | 模板默认或 **20～24** | — |
| 机位 | 提示词写死「完全固定、无运镜」 | 防空抖 |

一次 Run 只要求 **一种动作**（优先烛火）。

---

## 三、稳定提示词（复制用）

**Positive：**
```text
中国传统手绘动画风格，机位完全固定，无运镜，无抖动，
仅烛火轻轻摇曳闪烁，
人物面部五官完全锁定，不眨眼，不张嘴，不变表情，不转头，
身体静止，发丝与衣服基本不动，
严格保持参考图像的脸、发型、服饰与色彩，
冷青夜色，安静，高质量，流畅
```

**Negative：**
```text
五官变形，脸部扭曲，狰狞，恐怖，表情乱变，面孔融化，
身份漂移，眼睛错位，牙齿错乱，
运镜，推拉摇移，抖动，晃动，
走路，转身，大幅动作，眨眼，张嘴，
静态冻帧与剧烈抖动并存，低质量，模糊，闪烁
```

出稳了再逐步加「衣袖微动」——**不要**一次加眨眼+呼吸+推镜+衣袂。

---

## 四、稳定工作法（比换大模型重要）

1. **多抽少改**：同一设置连跑 4～8 条，挑脸不崩的，不要每条都大改参  
2. **短镜头拼接**：成片用很多段 2～3 秒，不要一段 5～10 秒硬造戏  
3. **动作分级**  
   - A 级（最稳）：只动烛火 / 烟雾 / 灯光  
   - B 级：衣袖、头发微动  
   - C 级（易崩）：眨眼、说话、转头、走路 → 后期再碰  
4. **定妆图**：用脸最清晰、姿态端正的那张；避免大俯仰、半残构图  
5. **保存配方**：工作流另存为 `wan22_5B_i2v_稳定微动.json`

---

## 五、仍不稳时的本地备选（仍不接云）

| 方案 | 何时用 |
|------|--------|
| 继续 5B + 更短 length（33～49） | 仍轻微毁脸 |
| **LTX-Video 2B** | 要更快草稿；锁脸一般不强于 Wan5B |
| 静帧差量剪辑 | 两张极近静帧在达芬奇里做 cross dissolve / 轻微缩放，零毁脸（应急） |

暂不推荐当主力：Wan14B、Hunyuan 大杯（16GB 难「稳产」）。

---

## 六、验收标准（打通即过）

一段视频同时满足：

- [ ] 脸还能认出是定妆角色（不狰狞）  
- [ ] 至少烛火在动  
- [ ] 没有明显运镜乱抖  
- [ ] 能进达芬奇播放  

达到就可以去拼第一条试片；脸 95 分、动作炫不算现阶段 KPI。

---

## 七、和费用的关系

整条链：电费 + 磁盘。  
质量上限本地会低于顶级云端，但用「短镜头 + 微动 + 多抽选片」可以把短片流程稳定跑完。
