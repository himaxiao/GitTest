# 分镜生产规范：表 → 图 → 下游可读

> 回答三个问题：分镜是不是文生图/图生图？怎么控到符合预期？怎样才算生产标准、能交给后续环节？

---

## 1. 先拆开：「分镜」有两层

| 层 | 是什么 | 靠什么做 | 给谁用 |
|----|--------|----------|--------|
| **A. 分镜表（合同）** | 文字+表格：镜号、时长、景别、运动等级、旁白、首帧文件名 | **人写**（可让 LLM 起草，你定稿） | 全流程的「唯一说明书」 |
| **B. 分镜图/关键帧（画面）** | 每镜一张（或首尾两张）静帧 | **文生图为主；图生图/垫图为辅** | Wan I2V、剪辑、质检 |

**不是**「随便文生图碰几张就算分镜」。  
正确顺序：

```text
分镜表定稿（Gate0）→ 定妆锚点（Gate1）→ 按表文生/图生出关键帧（Gate2）→ 表上填写文件名 → 下游只认表+文件
```

文生图/图生图 = **执行表里的画面**，不能代替表。

---

## 2. 关键帧用文生还是图生？

| 情况 | 推荐 | 原因 |
|------|------|------|
| 新场景、新景别（S01 荒园门） | **文生图** | 构图自由度大 |
| 同一人换景别（S03→S04） | **文生 + 同一锁定词**；有垫图能力再用图生/参考 | 锁妆服 |
| 半身要补腿、横竖转换 | **图生图/扩图** | 保留上半身 |
| 已有关键帧只微调光色 | 低 denoise 图生图 | 防大漂 |

试片默认：**Qwen 文生图出关键帧**；身份靠锁定词+定妆文件，不靠每镜换模板。

## 3. 怎样控制「符合预期」

控制点在 **表字段**，不在玄学抽卡。

### 3.1 分镜表必填字段（生产最小集）

每镜至少：

| 字段 | 作用 | 下游怎么读 |
|------|------|------------|
| 镜号 `S01` | 唯一 ID | 文件名、时间线轨道 |
| 时长 | 剪辑长度、旁白容量 | 剪辑；I2V 条数估算 |
| 景别 | 构图约束 | 写进出图提示词第一句 |
| 画面内容（一句话） | 预期画面 | 出图/验收 |
| 运动等级 A/B/C | 视频自由度 | Wan 提示词白名单 |
| 允许运动 / 禁止运动 | 防崩 | 原样进 I2V |
| 旁白/对白 | 声画 | 录音与卡点 |
| 首帧文件 | 视觉锚 | `Load Image` 只认这个 |
| 状态 | 待关键帧/待视频/过审 | 排期 |

没有「运动等级 + 首帧文件名」的镜子，**禁止进 Wan**。

### 3.2 出图时只改「景别+本镜动作句」

```text
[景别句] + [本镜画面一句] + [固定身份锁定段] + [固定风格尾句]
```

禁止每镜重写整段人设。预期靠 **锁定段不变、景别句变**。

### 3.3 抽卡上限 = 控制手段

- 每镜最多 **4 张选 1**  
- 选不中 → 改景别句/构图词，或回到定妆，**不**无限抽  
- 选中后立刻改名归档，写入分镜表「首帧文件」列

## 4. 什么叫「符合生产环节标准」（下游可读）

下游（I2V / 剪辑 / 未来的 LoRA）只认下面这套，不认聊天记录里的「我觉得这张行」。

### 4.1 交付包（一镜一份逻辑）

```text
03-storyboard/分镜表_xxx_v01.md     ← 总表
04-keyframes/KF_S01_荒园夜门_v01.png ← 表内写明的路径
（可选）04-keyframes/KF_S01_尾帧_v01.png  ← 仅当要做首尾帧插值时
```

### 4.2 关键帧验收（给 I2V 用）

- [ ] 画幅与成片一致（试片 16:9 优先）  
- [ ] 主体完整程度符合景别（全景有脚/门；中近景脸清晰）  
- [ ] 身份与定妆七成以上一致（妆服可指认）  
- [ ] **无多余运动暗示**（关键帧是静的；动写在表的运动栏）  
- [ ] 文件名 = 表中「首帧文件」一字不差  

### 4.3 分镜表验收（给全组/未来自己用）

- [ ] 镜序连续，时长加总 = 目标成片  
- [ ] 每镜运动等级已填，且与「允许/禁止」不矛盾  
- [ ] 旁白可按镜切开或已标全局旁白段  
- [ ] 状态列可筛选「待视频」列表  

**可读性标准一句话：**  
陌生人只打开「分镜表 + `04-keyframes/`」，不看聊天记录，也能按表跑完 Wan 并剪进时间线。

---

## 5. 推荐作业顺序（单集）

```text
① 填分镜表（先空着首帧文件名）
② 定妆进 anchors，锁定词进 tags.md
③ 按镜号依次文生关键帧 → 改名 KF_Sxx → 回填表
④ 表状态改为「待视频」
⑤ Wan：Load 表指定文件 + 表内运动白名单
⑥ 成片后表状态改为「已完成」
```

---

## 6. 和「漫剧分镜」的差别（避免学歪）

| | 红果式云端漫剧 | 你本地可控产线 |
|--|----------------|----------------|
| 分镜图 | 常直接当 I2V 输入，平台内闭环 | 同样，但 **必须先有表** |
| 一致性 | 靠平台角色参考 | 靠定妆文件 + 锁定词 + 命名 |
| 标准 | 能过审竖屏连载 | 表+文件可复现、可复盘 |

云端教程里「出一组分镜图就开做」可以；本地要把 **表当作 API 合同**，图只是 payload。
